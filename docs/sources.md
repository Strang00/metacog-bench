# Sources

Where each skill's idea comes from. An anchor is a pointer to a research line, not proof that our wording works for an agent; transfer from human studies is an analogy.

## Framework
- Flavell 1979 — metacognition as knowledge and regulation of one's own cognition
- Nelson & Narens 1990 — monitoring and control between meta- and object-level
- Zimmerman 2000 — self-regulation phases: forethought, performance, self-reflection (our G phase is an addition)
- Liu & van der Schaar 2025, ICML position paper — learning to learn for agents
